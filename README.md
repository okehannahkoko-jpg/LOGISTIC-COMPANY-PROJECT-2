# Temi Tee Logistics Company – Data Analysis with Power BI

## Project Overview

This project involved analysing logistics company data using Microsoft Power BI. I worked with a logistics dataset covering different aspects of the company's operations, including shipments, revenue, carriers, warehouses, product categories, delivery delays and returns.

I created a five-page interactive dashboard to explore the data, compare performance and present the findings in a visual format.

## Project Objectives

The main objectives of this project were to:

- Analyse the company's shipment and revenue performance.
- Compare the performance of different carriers and shipping modes.
- Examine warehouse activities and shipment distribution.
- Understand revenue across different product categories.
- Analyse delivery delays and shipment returns.

## Tools Used

- **Microsoft Excel:** Dataset.
- **Microsoft Power BI:** Data analysis, visualisation and dashboard development.

## Dashboard Overview

The dashboard consists of five main sections:

### 1. Executive Summary
Provides an overview of the company's performance, including total shipments, revenue, on-time delivery rate, average delay and customer rating.

### 2. Carrier and Mode Performance
Examines carrier performance across different shipping modes, including delivery rates, average delays and shipment values.

### 3. Warehouse and Route Analysis
Explores shipment distribution across origin warehouses, revenue by destination city and lost shipment values.

### 4. Product and Revenue Analysis
Shows revenue generated across different product categories and how revenue changes across quarters and years. It also presents the company's total shipping cost.

### 5. Delay and Return Analysis
Examines delivery delays, delay rates and the different reasons for returned shipments.

## Key Figures from the Dashboard
